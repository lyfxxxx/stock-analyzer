# 标签系统

## 概述

标签系统为股票提供灵活的分类和筛选能力。标签分为两类：

- **自动标签（14个）**：系统根据股票数据自动计算并分配，不可编辑或删除
- **手动标签**：用户自定义创建，可编辑、排序、删除

自动标签和手动标签共同作用于股票的标识、筛选和股票池分组。

---

## 自动标签

系统内置 14 个自动标签，覆盖 5 个维度：

### 触发规则

| 类别 | 标签 | 条件 |
|------|------|------|
| 市场 | 港股 | `market === 'HK'` |
| 市场 | A股 | `market === 'A'` |
| 估值1 | 估值1低估 | `valuation1 < 10` |
| 估值1 | 估值1合理 | `10 <= valuation1 < 20` |
| 估值1 | 估值1高估 | `valuation1 >= 20` |
| 估值2 | 估值2低估 | `valuation2 < 10` |
| 估值2 | 估值2合理 | `10 <= valuation2 < 20` |
| 估值2 | 估值2高估 | `valuation2 >= 20` |
| 市赚率 | 市赚率低估 | `prr < 0.5` |
| 市赚率 | 市赚率合理 | `0.5 <= prr < 1.0` |
| 市赚率 | 市赚率高估 | `prr >= 1.0` |
| 目标价 | 低于目标买入 | 当前估值或 PRR 低于买入阈值 |
| 目标价 | 目标区间内 | 当前估值或 PRR 在买入与卖出阈值之间 |
| 目标价 | 高于目标卖出 | 当前估值或 PRR 高于卖出阈值 |

### 规则说明

- **估值标签**：`valuation1` 为 null 时不生成对应标签
- **市赚率标签**：优先使用 `prrAdjusted`，无数据时回退到 `prrBase`；两者均为空时不生成
- **目标价标签**：仅在目标价配置启用时生效。传统目标价法按 `valuation1/valuation2` 计算，PRR 目标价法按 `prrAdjusted/prrBase` 计算

## 标签管理

### 打开标签管理器

点击页面上的标签管理按钮，从右侧滑出标签管理器面板。

### 手动标签操作

| 操作 | 说明 |
|------|------|
| 创建 | 输入名称、选择颜色，点击添加 |
| 编辑 | 点击标签进入编辑模式，修改名称或颜色 |
| 删除 | 删除手动标签，所有关联的股票标签自动解除 |
| 排序 | 拖拽标签调整显示顺序 |

### 约束

- 自动标签不可编辑、不可删除、不可从股票移除
- 手动标签名称最多 20 个字符
- 标签颜色从预设的 12 色调色板中选择

---

## 标签分配

- **自动标签**：在获取或刷新股票数据时自动重新计算，替换过期标签
- **手动标签**：用户在股票详情页或股票列表中手动添加/移除

---

## 筛选和股票池

### 标签筛选

通过 `TagFilter` 组件按标签筛选股票列表：

- 支持多选标签（与逻辑）
- 自动标签和手动标签分组展示
- 选中标签数量显示在筛选按钮上
- 支持一键清除所有筛选条件

### 股票池

标签池（TagPool）提供更灵活的股票分组：

- 每个池包含一组标签
- 股票匹配任一标签即归入该池
- 可创建、编辑、删除标签池
- 支持默认池和自定义池

---

## 页面展示

| 页面 | 展示方式 |
|------|----------|
| 股票列表 | 每只股票行显示其标签徽章，彩色圆点或文字标签 |
| 股票详情 | 标签区域展示所有已分配的自动标签和手动标签 |
| 筛选面板 | 标签分组展示，支持多选筛选 |

---

## 存储

所有标签数据持久化在 IndexedDB 中，包含三个数据表：

| 表 | 说明 |
|----|------|
| tags | 所有标签定义（含自动和手动） |
| stockTags | 股票与标签的关联记录 |
| tagPools | 标签池配置 |
